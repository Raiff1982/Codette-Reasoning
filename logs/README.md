# Logs And Transcripts

This folder is for real run logs and transcript captures.

Recommended contents:
- multi-perspective chat transcripts
- before/after bug-fix traces
- benchmark console logs
- saved diagnostic outputs when relevant

Suggested naming:
- `transcript_YYYYMMDD_topic.md`
- `runtime_log_YYYYMMDD_case.txt`
- `before_after_YYYYMMDD_issue.md`

Good transcript candidates:
- a multi-perspective reasoning task
- a continuity-recall example
- a valuation/risk-frontier example
- a web-research query with cited sources

When possible, pair transcript files with:
- the exact prompt
- the exact response
- the model backend used
- whether web research was enabled
- links to related benchmark or test artifacts
