# Codette Skills Repository

## Purpose
This repository packages Codette documentation into cross-platform skills files for use in agent systems that support reusable instruction sets.

## Contents
- `core_SKILL.md`: Core runtime, architecture, and usage.
- `benchmark_SKILL.md`: Benchmarking, evaluation, and reproducibility.
- `memory_SKILL.md`: Cocoon memory, provenance, and continuity.
- `integration_SKILL.md`: Platform and deployment integration.

## Usage
Place the skill files in the target platform’s skills directory or package them according to that platform’s import rules.

## Maintenance
Keep the skill files aligned with the main Codette README, changelog, and benchmark reports.
