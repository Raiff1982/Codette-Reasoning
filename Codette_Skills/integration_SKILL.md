# Codette Integration

## Purpose
This skill enables Codette to integrate with platform workflows for publishing, versioning, and deployment.

## Trigger Conditions
Use this skill when the user asks to:
- publish Codette models or research,
- integrate with Hugging Face, Zenodo, GitHub, or Azure,
- deploy or package Codette,
- or manage releases and citations.

## Scope
This skill covers:
- Hugging Face model and dataset management,
- Zenodo publication and DOI handling,
- GitHub repository and release workflows,
- deployment packaging,
- and citation synchronization.

## Workflow
1. Identify the target platform.
2. Prepare the Codette artifact or release package.
3. Upload or deploy using the platform’s accepted format.
4. Record the version, DOI, or release tag in the documentation.

## Notes
- Keep all releases aligned with the main README and changelog.
- Preserve the RC+ξ attribution correction.
