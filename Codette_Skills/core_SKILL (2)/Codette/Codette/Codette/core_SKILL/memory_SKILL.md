# Codette Memory

## Purpose
Codette memory stores reasoning exchanges as cocoons with provenance, integrity scoring, and retrieval support.

## Trigger Conditions
Use this skill when the user asks about:
- cocoon storage,
- memory retrieval,
- provenance,
- continuity,
- drift detection,
- or migration and backup of reasoning artifacts.

1. Identify the cocoon type.
2. Validate provenance and integrity fields.
3. Retrieve or update memory through the canonical memory subsystem.
4. Report any drift, unresolved tension, or continuity signals.
